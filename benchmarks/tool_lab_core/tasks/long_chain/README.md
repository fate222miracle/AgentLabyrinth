# 跨文档证据任务 v1

2026-10-12真实失败复核后当前Task为1.3.0（ADR-029）：新评分order_status_v2按完整证据集合比较，不要求字典序；漏项、重复、额外或未实际读取仍失败。新工具集v1.3.0只展示本任务允许的文档工具，每轮一个行动；read_document说明明确可直接读取已读正文引用的ID，不需重复搜索。旧产物按旧版本读取/恢复，初版字典序不再是新题成功条件。

来源：AgentLabyrinth 独立自建仿真，development；不属于外部Benchmark或真实企业记录。原V0.1十二题不变。设计与评分边界见ADR-028。

公开描述规定最终Status与完整证据要求，正文引用给出关联关系，末端状态不能替代此前依据；旧版/错案文档是干扰。精确答案、完整证据集合及成功阅读事件评分。允许任意正确路径，不检查凑步数，不要求模型复现示例顺序。独立规则推理、业务写入或真实外部用户模拟不在本任务集。

网页ToolLab下直接搜索“退货”“配送”“退款”，支持现有实时SSE、证据节点、历史回读、对照与只读MCP。当前Task版本1.3.0，上限10步，累计Token20000；MiniMax实测三文档末轮9493Token，初版8000不足，旧产物和显式低预算保持。模型仍可能耗尽预算或上游失败，失败照常保存。Fake参考实现从公开可见阅读正文跟随Next document、解析终端Status并收集已读证据，不读取goal_conditions。

full与窗口足够时Fake通过，窗口1会漏交早期证据。这个现象用于检验平台的窗口和评分，不代表真实模型效果；工具保留的acquired_evidence也可供真实模型恢复证据ID。真实结果、源码与失败验证见docs/learning/V0.3-linked-evidence-20261012.md。
