# 单次运行配置：消除空白与设置堆叠

日期2026-10-14；需求V0.6，UI呈现调整，不改变API/策略/预算或评分，不提交GitHub。

## 问题与依据

任务目录有max-height，右侧却包含全部展开的高级参数，CSS Grid一行高度由右侧决定，左侧目录结束后形成大块空白。缩小字体或继续增加右侧折叠控件不能消除这项布局原因。

参考原始来源：

- [LangSmith配置窗口](https://docs.langchain.com/langsmith/managing-model-configurations)：模型、工具和格式分别组织，设置入口与主工作区分离。借鉴分类，不增加不存在的配置保存/权限功能。
- [Langfuse Playground](https://langfuse.com/docs/prompt-management/features/playground)：模型额外参数按需展开。借鉴默认先看常用项，不复制其多提示编辑流程。
- [NN/g渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)：少用或高级能力放次级区域，保持常用操作简单。未据此声称用户完成速度已实测提升。

## 实施决定

左侧任务列表保持可搜索、滚动和实际选中状态。右侧紧凑操作台只显示模型、Runtime、当前运行摘要和主启动按钮；模型目录长说明折叠、可键盘滚动。任务目录330px上限用于保持两侧基础内容接近，不硬设整行高度。

高级设置移为两栏下方独立整行，按工具/容错、上下文/记忆、运行预算分组三列；中等屏两列，小屏单列。展开此行不能改变基础任务/模型所在行的高度。保留所有控件ID、数值和事件处理，切换任务不覆盖自定义预算，历史仍只读。

上下文窗口和记忆容量紧凑并排，条件不适用时不显示；简短说明常驻，较长限制使用原生details。下次运行摘要显示草稿实际上下文/记忆/步数/时限，不展示假估算。原生select/radio/input继续提供键盘与屏幕阅读器语义；不用额外抽屉组件、选项卡或自定义菜单依赖。

防错：原生高级details的summary CSS只作用直接子元素，避免嵌套策略说明继承顶层加减号、字体和边距。更多设置展开和关闭不能POST、重置模型或改写历史。布局与失败验证、截图证据见任务卡。
