ADR 见 `docs/adr/ADR-011-tool-lab-checkpoint-resume.md`，状态 Accepted。应用层 `CheckpointStore` 与共同 `EpisodeSession` 的可迁移状态已实现；Reference 和 LangGraph 都可恢复。`run_checkpointed_episode` / `resume_checkpointed_episode` 已用于 ToolLab 单次 API，网页有待恢复入口。浏览器 Fake 故障演练成功，ID 与证据见 current-state；真实模型中断恢复仍待探索验证。

最小交付边界：先支持 ToolLab 的单个 Episode，在安全边界（工具执行后、下一次模型调用前）写版本化 Checkpoint；进程退出后用同一 Episode ID 恢复。必须保存当前 Step、Agent 可见消息、完整预算、已执行 Call ID、环境 Snapshot、Runtime 下一节点、Trace 因果链和 Agent/Task/RunConfig 哈希。恢复前校验版本与哈希；工具动作须有幂等键，恢复不能重复已提交写操作；Trace 留下恢复事件。Reference 和 LangGraph 两种 Runtime 都通过同一契约，不得只为其中一种实现。现有 JSON Episode 与 Experiment 仍可回读。
