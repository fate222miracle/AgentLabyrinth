## 技术之外仍未验收的部分

当前唯一规划样本沿用received/damaged/required三事实规则，公开描述已列复合条件，登记仍直接提供所需引用。它可验证声明工具、预算、来源与UI机制，但**不足以证明真实的分支规划/依赖决策优化**。Fake只是预先声明facts→decide后沿旧公开规则求解，两侧均通过且右侧多一次调用；不说明规划有收益，也不能把两项声明模板当被测模型的自主规划能力。

下一项应先提出有区分度的具体任务方案：同样信息与预算下观察子目标遗漏/分支适用性/动态依赖，允许基线走有效路径，不强制规划侧独有工具作为得分条件。新任务/协议先ADR，不能为制造差异而削弱基线、提高右侧预算或隐藏失败。也可以先按已定义的一模型/一题/固定预算方案做探索，但当前未授权本轮继续真实调用，不自动消耗。
