# 可信模型准入与通用工具说明修复

负责人 2026-10-11 授权处理推荐模型实测发现的两个共性问题。权威需求仍为 V0.6，决策为 Accepted ADR-027。

## 范围

- GLM Flash 目录缺失、推理可用：正式配置中的精确布尔例外同时用于元信息和共享执行检查。默认仍进行目录预检；客户端不能提交例外。
- ToolLab 文档任务提交说明误指订单查询：新 API 固定工具集 v1.1.0，旧恢复/重跑/冻结计划沿用原版本。字段、权限、预算、评测和 BFCL 不变。
- M3、Flash 加为实验候选，M2.7 保持默认；Kimi 不加入。不得以目录可见或一次通过承诺持续可用。

## 验收

- [x] 目录缺失/失败、非布尔配置和客户端伪造字段边界。
- [x] Provider 失败不自动重试、不改记成功，未配置模型仍拒绝。
- [x] 两 Runtime、新旧安全点/重跑、MCP 参数说明、同版本成对计划及严格证据校验。
- [x] 固定回归按基线工具版本执行，旧基线不改写；新版本基线也可运行。
- [x] 完整共享门禁、Edge 候选说明展开/选择/零 POST 验证。
- [x] 正常 API/SSE 真实小样本完成：Flash 通过，M3 提交答案带多余原文而评分失败；不调整评分掩盖失败。详见学习交接。
