## 验收标准

- 两种 Runtime 的主调度流程独立，且共用预算、Provider、Validator、Executor 与 Trace 语义。
- 两种对照轴的固定变量已在 Application 边界拒绝非法组合；每个 Pair 串行运行且保存两侧 Episode。
- Runtime 对照中 `retry_eligible`、挽救率及挽救分子为 null/不适用语义，前端不展示成零挽救。
- 旧产物仍可读取，API/Web 可执行和回读；单次及成对 Trace 可穿透。
- Ruff、mypy、pytest、Web 构建及浏览器验收结果都有实测记录；未执行的一项明确标记未执行。
- 单模型真实小样本仅作为探索性结果，不作为 Benchmark 全量分数。
