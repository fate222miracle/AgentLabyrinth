# V0.2 M1：LangGraph Runtime Adapter Bootstrap

SSOT：`docs/product/requirements.md` V0.6。ADR：`docs/adr/ADR-009-langgraph-runtime-bootstrap.md`。

## 历史目标（已完成）

以最小可运行实现确认 LangGraph 能通过既有 `AgentRuntime` Port 执行 Episode，并保持统一结果与 Trace 契约。

## 验收

- LangGraph 依赖只进入 Runtime Adapter 边界。
- Bootstrap Graph 可异步执行现有 Runtime。
- 同一 Fake Provider、Task 与 Seed 下，适配前后的公开 Episode、Evaluation 与事件类型一致。
- 全量 Python 质量门通过。

## 历史边界

Bootstrap 不是独立控制循环，不计为 `HandwrittenRuntime × LangGraph` 对照完成。该阶段随后由 ADR-010 取代；不得将 Bootstrap 当作当前实现或实验结论。

## 执行结果

2026-09-22：LangGraph 1.2.12 已锁定；Bootstrap 契约测试通过。全量门禁为 Ruff、mypy、`101 passed`，保留 1 条 Starlette 上游弃用提示。后续独立节点实现见 `docs/tasks/V0.2-m1-runtime-comparison-copilot.md`，其验收不能复用本历史门禁结果。
