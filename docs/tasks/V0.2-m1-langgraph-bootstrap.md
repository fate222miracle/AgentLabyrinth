以最小可运行实现确认 LangGraph 能通过既有 `AgentRuntime` Port 执行 Episode，并保持统一结果与 Trace 契约。

## 验收

- LangGraph 依赖只进入 Runtime Adapter 边界。

- 全量 Python 质量门通过。

## 明确边界

Bootstrap 不是独立控制循环，不计为 `HandwrittenRuntime × LangGraph` 对照完成。下一任务是把模型调用、校验、工具执行和终止路由实现为 LangGraph 节点，同时复用现有公共组件。
