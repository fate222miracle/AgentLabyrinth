# V0.2 再次复核与状态正确性收尾

依据：唯一需求 `docs/product/requirements.md` V0.6、AGENTS、Accepted ADR-014/015/016/019/020、current-state 和 UI 规范。负责人授权再次检查，确认问题及时修复，并在现有版本范围内继续推进。

## 范围与顺序

1. 只读审查 Runtime/预算/恢复、API/持久化、Web/Job/历史导航；辅助审查不改文件，Codex 串行修复。
2. 修复已确认的 Token 超限遗漏费用、Job 创建/恢复迟到响应覆盖导航问题；以实际复现决定其余修复。
3. 增加相应回归保护，减少下次开发再次破坏终态统计或页面状态的风险。不改核心 Schema、接口、评测口径。
4. 完成质量检查和浏览器验证，记录可推进的下一步与仍未签收事项。

不引入数据库、多 worker、登录、多 Agent 或新模型；全局 Token 和最终免费模型清单继续按 ADR-019 延期。本次不自动提交或推送，不宣称整版 V0.2 验收。

## 模块契约与验收

- BudgetTracker 先记录已返回响应的完整用量与费用，再维持既有预算判定优先级；终态和 Checkpoint 不漏统计。
- Web 请求完成只更新仍然属于当前导航的页面；离开的任务可在后端继续，迟到响应不得夺回 URL 或清除新请求的加载状态。
- 验证两个 Runtime 的一致终止和费用记录、Job 导航竞争、完整 Python 门禁、Web 构建与状态测试、四套 Fake 回归及真实浏览器。
- 交付源码阅读指南、调用链、状态和失败路径、实际结果与 current-state。未运行的真实模型和现场签收明确保留。
