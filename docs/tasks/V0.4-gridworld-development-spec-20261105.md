## 目标

交付一个可 Fake 验收、保留旧 ToolLab 行为的 GridWorld `key-door-001-v1` 首片：确定性 Environment 规则 → 真实到达的实时执行展示 → 私有快照保存/恢复与历史只读回读。三阶段串行，不并行修改同一核心边界。

## 阶段 1：环境规则

完成后必须满足：

- 固定地图、工具 Schema、观察/记忆、动作计数、非法行动和终态严格按已批准 ADR-045。
- `Environment.snapshot()/restore()` 提供版本化私有恢复状态；`Environment.public_state()` 只返回当时 Agent 可见投影。
- Runtime 保留私有状态用于 checkpoint 和内存中的 Evaluation；初始/动作 Trace 状态是 public projection；Runner 评估结束后才将持久化 `EpisodeResult.final_state` 投影为 public state。
- 任何公开投影失败都 fail-closed；工具执行、Evaluator 或恢复出错时只允许最后一份已验证的 public projection 或空状态，绝不回退到 private snapshot。
- 规则内非法动作是正常结构化 Observation，不是环境异常或工具失败。
- 完成 Domain Environment contract、8 动作固定路线、任意 Seed 确定性、状态转移、遮挡/最后已知状态、非法行动、保存/恢复状态分离和完整预算单测。
- 第 16 个动作成功可成功结束；第 16 个未成功不得有第 17 个模型请求或环境动作。
- 累计 Token 正好达上限时允许当前 schema/permission 验证通过的动作完成、然后禁止下一请求；超过累计上限时完整记账但拒绝该动作。单次 completion=800 可执行，=801 完整记账但不调用工具/环境。

## 阶段 2：实时展示

阶段 1 的契约测试通过后，再接 Fake 单次 API 与当前 Web 执行舞台：

- 初始 Observation、模型请求/响应、行动、工具反馈和 Agent 可见环境更新都来自真实追加事件；禁止合成/重播“实时”进度。
- 在首帧、每个环境动作、终态产物验证地图投影与 Agent 当前知识一致；无未探索真值。
- 规则内拒绝显示为可理解的环境反馈，不呈现成工具/服务器故障。
- 最终答案/终态、评测结论、资源统计独立呈现；切换 Replay 游标只改变历史帧，不覆盖当前最终产物。
- 假服务实际浏览器运行到成功、非法行动与预算终止；浏览器 Network 确认运行前无 POST，显式开始后仅按产品流程 POST，回读/刷新只 GET。记录 Episode ID、Trace 和真实 HTTP 状态。
- 首切片只开 Fake 闭环；不运行真实模型/Judge，不接 GridWorld Experiment。

## 阶段 3：保存恢复与历史回读

阶段 2 的单次实时闭环通过后，再实施 SQLite Checkpoint/Resume 与只读历史：

- 私有快照和 Agent 知识投影分别验证/恢复；恢复点覆盖已探索、持钥匙、门已打开等状态，不能用服务端全图刷新 Agent 记忆。
- 安全点含环境版本、预算、Runtime 状态、完整 Trace 前缀；预算与 16 轮边界跨恢复不重置。新进程只追加事件，不重复已完成工具/模型调用。
- SQLite 完成产物只保存公开 Episode `final_state` 和 Agent 可见 Trace；私有快照仅处于服务端恢复记录，不由普通 Episode GET、实时 SSE 或 Web 读取。
- API 历史 GET、页面刷新、URL 直接打开、前进/后退及 Replay 前缀均不 POST、不触发模型或工具。
- Fake 跨进程退出/重启后按 Episode ID 回读；核对状态、Trace 顺序、终态和哈希。

## 跨阶段兼容、测试和交付

- 先冻结旧 ToolLab 代表性 Trace/API/Replay/Checkpoint 哈希；保持历史读取、Agent/Task/RunConfig 配置哈希和 SQLite Schema，不做旧数据迁移。
- `Environment.public_state()` 是共享 Port 的必需显式方法，不设置 `snapshot()` 默认回退。兼容核对覆盖 `ToolLabEnvironment`、继承它的 `MCPToolLabEnvironment`、`BFCLEnvironment`、契约/多轮测试替身（`StubEnvironment`、`DummyMockEnvironment`）、执行时限测试子类及新增 Fake/Mock 环境；ToolLab/MCP 公开投影须与旧 Replay state 等值，BFCL 单调用/评测语义不变。
- 代码审查按层验证：Environment private/public 投影 → Provider 输入与 Trace/SSE → Evaluator 输入/输出 → Episode Artifact/API → React 实时/历史 Replay → SQLite 恢复。
- 泄露测试对每个公开序列化边界递归扫描隐藏目标、完整地图、隐藏动态状态与私有快照字段；只允许私有安全点包含服务端恢复状态。
- 预算 Fake 测试逐项覆盖：16轮、单次 800/801、累计 16,000 等值/16,001 超值、12,800 completion 等值/超值、300,000ms 和已知估算 USD 1.00；未知用量/费用保持未知，已发请求完整入账。单次输出或累计 Token 超限不执行当前动作；累计 Token 恰好达限完成当前合法动作后不再请求。
- 300,000ms 预算使用现有 `Budget.schema_version=1.1`，其余预算值使用既有字段；测试旧 ToolLab 的旧版 Budget/ModelConfig/TaskSpec 配置哈希和回读不变。
- 故障注入覆盖 Environment.step、Evaluator、public_state、checkpoint load/validate/restore 失败，确认公开 artifact/Trace 只含最后有效公开投影或空状态；特别断言任何失败路径均不从私有 snapshot 兜底。
- 每阶段完成后更新 `docs/handoffs/current-state.md`；核心实现完成后新增源码阅读顺序、调用链、状态变化、失败路径及实际实验结果的学习交接。
- 最终使用项目完整质量门禁 `uv --cache-dir .uv-cache run --locked python -m scripts.check`，记录实际 Edge/端口/产物和所有失败过程；本机结果不冒充远端 CI。

## 非目标与限制

- 不实现多 Agent、通信、随机地图/编辑器、资源合成、Observer 全图视图、路径效率分数或 GridWorld Experiment。
- 不安装 MiniGrid 或其他依赖，不复制研究项目代码。
- 不调整旧 ToolLab 任务、评分、公开 Schema、API 语义、CSV 或历史产物。
- 不真实模型/Judge 请求、提交/推送/建 PR、改原工作区 SQLite 或做历史迁移；如需其授权，另行明确申请。
