# V0.2 前端接口边界与自动验收收尾

依据：唯一需求 `docs/product/requirements.md` V0.6 §25.2、§27、V0.2 路线，AGENTS、ADR-014/018/021 与 current-state。负责人授权按需求继续 V0.2 收尾；保留已有未提交改动。

## 范围与模块契约

1. 提取 Web 接口 Schema 和推导类型；JSON 必须以 unknown 进入校验，校验成功才更新页面。覆盖元数据、Episode/Experiment、Job、历史看板、恢复 ID 列表与实时 Trace。
2. 校验已消费字段、版本、数值及结果身份；保留历史可选指标的 null/缺省和未消费扩展字段，不补零、不重算、不改变后端公开 Schema 或评分。
3. 使用 Playwright 验证真实 Fake API + Web 闭环、回放无执行请求、错误数据拒绝及迟到受理不覆盖导航；测试服务不读取 Key、只允许 Fake，产物独立。
4. 接入统一质量脚本和 GitHub Actions；自动检查不得依赖真实模型或本机历史产物。

不增加 Docker、数据库、多 worker、AgentVersion 编辑器、模型或 V0.3。全局 Token 与最终免费模型清单继续延期。本轮不提交、推送或代替负责人整版签收。

## 验收标准

- API 数据不再用类型断言冒充校验；损坏数据有明确错误，旧兼容结果仍可读。
- 新建 Fake Episode → Trace → 独立 Evaluation → Replay 自动通过；回放不重新执行。关键错误和导航竞争可重复验证。
- Python 质量门禁、前端构建/单测/E2E 和四套 Fake 回归通过；CI 配置与本地同一命令链。未在 GitHub 实跑不宣称 CI 已通过。
- 交付依赖选择、源码阅读顺序、调用链、状态/失败路径、实际结果和 current-state。
