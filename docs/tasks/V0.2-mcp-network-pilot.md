# V0.2 课程网络实验：远程 MCP ToolLab 小切片

需求依据：V0.6 §0.4 与 Accepted ADR-012。先保留工作区未知改动，串行修改。首批只做固定文档任务的只读 `search_documents` / `read_document`，服务在另一进程的 `127.0.0.1` 端口运行；平台通过官方 MCP Client 实际调用。

验收顺序：固定数据隔离与工具契约 → 真实 Streamable HTTP 两进程调用 → Agent Episode 本地/远程对照 → 断开服务失败 Trace → API/Web 最小选择与展示 → handoff、learning、质量门禁。不得把 `goal_conditions` 发给 Server 或模型；不得用 HTTP JSON 路由冒充 MCP；不得把远程结果混作原生模型能力分数。

阅读顺序：需求全文 → AGENTS.md → ADR-012 → current-state → 本任务卡 → `packages/environments/tool_lab/environment.py` → Registry/Executor → Session/Runner → API/Web。实际状态、失败路径和复现命令随实现更新。
