## Copilot 当前任务

1. 保留“对照实验”和“单次运行”两条完整流程，逐步移除 `App.tsx` 中剩余内联视觉样式，复用现有类；不要为一次性样式创建组件或依赖。
2. 对照实验配置按“Agent 策略 → 模型 → 任务 → 高级配置 → 运行”排序。明确 Baseline 与 Recovery 的唯一差异是一次 `INVALID_ARGUMENTS` 纠错；主按钮显示真实执行次数，无任务或元数据未完成时禁用并给出原因。
3. 历史结果与下次运行草稿保持视觉分离。结果摘要压缩为 3–5 个信息组，保留成功分子/分母、挽救基数、Token 差值、步骤和耗时；未知费用与缺失指标不得显示为 0。
4. 成对表格使用文字状态，保留 Baseline/Recovery 评测结论、是否真实挽救、步骤/Token 和两侧 Trace 入口。不要整行铺红绿背景。
5. Trace 将事件类型映射为规范中的中文标签，原始事件名仍可查看；展开按钮设置 `aria-expanded`，事件缺少耗时时不猜测。不得展示或虚构思维链。
6. 请求进行中只显示准确说明、已等待时间和预计 Episode 总数，不显示虚假进度、阶段或取消能力。错误、空数据、加载失败分别呈现。
7. 清理剩余正式功能 Emoji；少量图标需要时使用同风格内联 SVG，不引入图标库。复制操作不要使用阻塞式 `alert()`，改为页面内短反馈。
8. 在 390、768、1280、1440px 检查页面整体无横向溢出；200% 缩放、键盘操作和减少动效保持可用。真实浏览器分别验证 Fake clean、invalid-then-success、历史 URL 回读、单次运行和 Trace。
