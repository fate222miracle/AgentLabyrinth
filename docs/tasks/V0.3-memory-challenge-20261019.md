## 目标

用登记数量、验收损坏数量、适用政策门槛三个分散事实计算批次资格；提供基础、大返回和版本干扰三种变体。任务价值是事实复用和资源/来源边界，不能只复制已有末端Status链。

1. **版本与边界**：v1.4.0仅为新任务采用推导答案文案，submit参数不变；document_rule公开模式、fact-unit-rule-v1任务协议，旧document/document_chain与文案保持。先补旧序列化/hash和工具说明拒绝/兼容测试。
2. **任务数据**：新增三个唯一TaskSpec（各version1.0.0、development）；原15个ToolLab和BFCL文件不改。基础三文档均提供必要事实，大返回原文保留并明确合成容量负载，版本题由登记决定政策。材料化后检查唯一性、目标计算、完整证据和整包字节，不在运行时偷偷生成/改题。
3. **Fake与评分**：从公开可见正文/记忆收集事实和版本，缺事实沿公开引用读取，齐全即可计算提交；原Evaluator v2不修改。验证改数值/版本/文档ID会影响预期、只改私有goal不影响Fake动作。不给模型注入判分目标。
4. **API/MCP**：新建按任务协议确定ToolSet并保存，混合矩阵两侧一致，旧恢复沿保存版本；固定MCP资料加载/客户端v1.4一致。本地/HTTP/断线与安全点恢复用Fake验证，不开放外部任意服务。
5. **Web成品**：现有ToolLab目录可检索三题，显式启动、SSE实时出现实际节点，资料侧栏展示读到的事实，最终输出显示实际推导结论/引用和评测。正式记忆轴、CSV、历史只GET及离线审查全链路可用；不增空页或新依赖。
6. **质量与交接**：相关失败测试→完整README门禁→来源/调用链/状态/实际结果与截图记录。Fake机制不当真实收益；后续单模型真实样本另按C决定，不自动扩大。

## 最小必验失败路径

- 参数错、未知/禁止工具、重复Call ID、第二次参数错仍按原边界终止。
- 仅有累计evidence ID而无数值正文不能凭空算出事实；空返回/失败无阅读证据。
- 使用旧版门槛得到另一答案失败，先读错版后读正确版可通过，不能因读过干扰项就判失败。
- M8192跳过大正文但重读后成功可通过；不强制大返回任务失败，不把容量压力伪装成长链推理水平。
- 缺早期事实时不得默认ineligible或直接提交私有目标；Fake预算耗尽仍保存真实失败。
- 历史配置、工具文案、Task版本及配置哈希保持；恢复/失败重跑不静默升级。
