# V0.2 UI 复验与课程演示固化

依据：需求全文 V0.6、Accepted ADR-012/013/015/016/019、current-state 和 UI 规范。负责人已授权接续产品收尾；此卡不替代需求。

## 范围与契约

- Web：复验键盘、快速历史/模式切换、失败状态、窄屏、必要文字与控件对比度；修复发现的展示问题。不改变评分、Trace 或 API。
- 演示：通过正式 EpisodeService 生成固定 Fake 成功、参数纠错对照、总时限、子进程安全点恢复，以及独立 MCP HTTP 成功/断线案例。隔离目录、重新生成 ID、失败非零退出；不读取 Key、不调用真实模型。
- 复现：锁定依赖安装、生成案例、隔离 API/Web 启动、三分钟讲解顺序、源码与失败路径指南。产物报告仅是诊断索引，不增加 Domain/持久化契约。
- 不实现全局 Token、模型目录迁移、数据库、多 worker 或外部写工具保证；不提交推送、不预签 V0.2。

## 验收标准

演示脚本实际运行并核验终态、独立评分、同 ID 恢复、已提交工具不重复、MCP 与本地结果一致；重跑拒绝覆盖旧目录。Web 构建/既有 Node 测试与后端质量门禁通过；浏览器检查真实保存案例、快速切换和键盘操作。实际浏览器 200% 与 OS 减少动画如工具无法控制，明确列为未验而非用等效宽度替代。更新 current-state、阅读指南和截图。

## 交付结果

新增固定生成器与一条命令隔离 API/Web 预览，完整网络案例实跑通过；四条集成测试验证跨进程恢复、失败用量、拒绝覆盖、拒绝真实 Provider 与端口接管。历史失败残留和必要文字可读性已修复，浏览器键盘/模式连续切换、390/768/1440 宽度与案例回读已抽查。最终 pytest 225、Ruff/mypy86文件、Web构建和Node11项通过。完整结果见 `docs/handoffs/V0.2-course-demo-20261001.md`、源码学习见 `docs/learning/V0.2-course-demo-freeze.md`。200%/OS减少动画、跨电脑实装、视频和整版签收未完成，不扩大验收结论。
