## 2.1 本轮补的三处缺口

1. **Web 对照右侧框架无专项 E2E**（矩阵上一版本自记缺口）：新增 `apps/web/e2e/runtimeTarget.spec.ts` 两项——① 保存的 PydanticAI 对照在界面显示 `Reference Runtime ↔ PydanticAI Runtime`，草稿选择器可切 LangGraph/PydanticAI 且说明“框架驱动单步节点，步间由适配器推进”，导出 CSV 的右臂为 `pydantic_ai`、`runtime_version` 为 `pydantic-ai-slim-2.57.0`，全程无写请求且保存实验不变；② 单次运行三种调度按钮可达且披露步间边界。
2. **复核 CSV 导出会偶发取消**：`EpisodeReviewPanel.downloadReviews` 在 `anchor.click()` 同一 tick 调 `URL.revokeObjectURL`，Edge 下偶发 `download.path: canceled`（全套 E2E 首次暴露）。已改为与 `App.downloadFile` 一致的“挂载→点击→移除→1s 后回收”，复跑 `episodeReview` + `runtimeTarget` 共 5 项通过，全套 66 项无失败。
3. **依赖审计红灯**：负责人批准后 `npm audit fix` 只改 `vite 6.4.3 => 6.4.5`（锁 3 行，`package.json` 范围 `^6.0.1` 未动），`found 0 vulnerabilities`；随后完整 `scripts.check` 通过。
