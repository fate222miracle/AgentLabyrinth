# V0.3 负责人 Fake 体验签收清单

日期：2026-11-04。此清单用于负责人体验集成后的产品闭环；不替代 requirements V0.6，不自动代表 V0.3 签收或 ADR-045 批准。仅使用隔离 Fake 服务，不调用真实模型/Judge，也不连接原工作区 SQLite。

## 开始前：启动隔离 Fake + SQLite 服务

在集成工作区打开 PowerShell 终端 A，为本次体验生成独立目录和服务身份：

```powershell
$runId = [guid]::NewGuid().ToString()
$previewDir = "artifacts\v03-owner-acceptance\$runId"
$env:AGENTLABYRINTH_E2E_API_PORT = '19040'
$env:AGENTLABYRINTH_E2E_WEB_PORT = '19041'
uv --cache-dir .uv-cache run --locked python -m scripts.web_test_server --artifacts-dir $previewDir --port 19040 --run-id $runId --sqlite
```

该命令保持前台运行。首次启动只允许创建新目录，并写入专用 Fake SQLite 标记；SQLite 文件位于该目录内。若路径不在当前工作区 `artifacts` 下、目录已存在或身份参数错误，服务拒绝启动。

在终端 B 启动 Web：

```powershell
$env:AGENTLABYRINTH_E2E_PROXY_API_PORT = '19040'
npm.cmd --prefix apps/web run dev -- --host 127.0.0.1 --port 19041 --strictPort
```

浏览器打开 `http://127.0.0.1:19041/`。确认页面可加载、Fake 模型可选。停止时只在各自终端按 Ctrl+C；不要停止其他端口的服务。记下 `$runId`、`$previewDir`，SQLite 目录留存到验收结束，不要复制或清理其他工作区数据库。
