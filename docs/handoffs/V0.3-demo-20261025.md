## 启动（项目根目录，分别两个终端）

首次准备：`uv sync --locked`、`npm.cmd --prefix apps/web ci`。

终端A：

```powershell
uv --cache-dir .uv-cache run --locked uvicorn apps.api.main:app --host 127.0.0.1 --port 8000
```

终端B：

```powershell
npm.cmd --prefix apps/web run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

若选“文档工具传输：MCP HTTP”，还必须在独立终端C启动工具服务（API/Web不会自动启动它）：

```powershell
uv --cache-dir .uv-cache run --locked python -m packages.environments.tool_lab.mcp
```

监听`127.0.0.1:8765/mcp`。没启动时模型可能正常返回，但第一次远程工具调用会`TOOL_EXECUTION_ERROR`。若只体验本地流程，在更多设置选择“本地 ToolLab”即可；不要将此类工具失败认作模型额度耗尽。
