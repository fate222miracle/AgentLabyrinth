## 4. 接手必须守住的边界

- 旧ContextPolicy1.0序列化/哈希保持，新1.1算法和大小组合严格验证；记忆只改变Provider输入，不裁剪持久历史。
- 空document:null不算读取；提议/开始/失败不算成功。观察者预览不调用工具，历史只读不取最终快照补前缀。
- 所有工具走Registry/Validator/Executor。多工具调用严格拒绝；参数错误最多一次纠错，未知/禁止/重复Call ID/第二次错误立即停。
- 记忆不伪造证据；旧任务评分和版本保持；新三场景的证据按已批准无序协议核验。
- 字节不是Token，未知费用/用量不补零；重复少不直接等于评分通过，少消息也不必然少总Token。
- 不重写历史产物；CSV按保存配置导出，草稿不污染历史；刷新/前进/后退只GET。
- 不加入数据库、向量库、摘要模型、Planning、第二框架、多Agent、地图引擎或新服务。不提交/推送/Tag/发布。
- 不输出Key，不复制`.env`到文档/前端/产物。真实调用不是本交接的必做项，不批量Seed×Repeat或自动换模型重试。
