# V0.2 可重新生成的课程演示

依据需求 V0.6 与 Accepted ADR-012/013/015/016/019。这是演示与复验交接，不是 V0.2 整版签收。最终免费模型与全局 Token 预算继续延期，数据库未实现。

## 换电脑准备

另一电脑需取得包含本轮变更的新提交，或带上本轮工作区源码；只取得旧 HEAD `038a3fa` 不包含新的 `scripts/course_demo.py`。不复制 `.env`、`.venv`、`node_modules` 或旧机器的 API Key。

安装 Python 3.12、uv、Node.js（本轮使用 Node 22.21.1、uv 0.11.18），在仓库根目录执行：

```powershell
uv sync --locked
npm.cmd --prefix apps/web ci
```

首次安装需要网络。以下固定演示只使用仓库内 ToolLab，不依赖 BFCL 缓存或上游模型；依赖安装完成后无需公网。若还要演示 BFCL，按 README 分别导入锁定的 Python/Java 子集，不擅自把上游原始题目打包入库。

## 生成与启动

先确认没有自己仍在运行的 MCP 服务占用 8765。生成器不会停止或接管已有服务；预览也拒绝已占用的 8000/5173。选择全新的输出目录，不重复使用已存在目录：

```powershell
$demoPath = Join-Path (Get-Location) ('artifacts/course-demo/' + [guid]::NewGuid().ToString())
uv --cache-dir .uv-cache run --locked python -m scripts.course_demo --artifacts-dir $demoPath
```

**退出码 0 且出现 `demo-index.json` 才表示生成验收完成。** 中途失败会保留诊断目录；先看错误和 `mcp-server.log`，修复环境后用新目录重跑，不覆盖旧证据。占用服务仅由你停止你自己启动的进程。

```powershell
uv --cache-dir .uv-cache run --locked python -m scripts.course_demo --preview --artifacts-dir $demoPath
```

这条命令一起启动隔离 API 和 Web，日志为 `preview-api.log` / `preview-web.log`。终端保持运行，浏览器打开 `demo-index.json` 中 `links` 的地址。Ctrl+C 停止本次启动的两个进程。预览只展示 Fake 模型，并在 Provider 创建前拒绝真实模型请求。它使用独立产物目录，正常 API 的历史不会被删除；同一浏览器原有近期历史可能显示“摘要暂不可用”，这是隔离目录没有该文件，不是产物丢失。

生成时独立 MCP 服务由脚本启动并在 finally 中停止。观看已保存动画不需要该服务；若要现场重新执行远程工具，需要另按 README 启动 MCP 服务。只启动 API 可用 `--serve`。`--skip-mcp` 仅用于本地排错，报告明确 `mcp_http_verified=false`，不能据此宣称网络案例通过。

## 固定案例与三分钟讲解顺序

| 时间 | 索引中的案例 | 画面与解释 |
| --- | --- | --- |
| 0:00–0:45 | `mcp_success` | 专注查看 → 播放全过程。输入、搜索/读取远程工具、最终答案与证据；Client → localhost HTTP → 独立 Server。模型为 Fake，HTTP 工具传输是真的。 |
| 0:45–1:20 | `comparison` | 同一任务/Seed/模型，只改变一次参数纠错；基线 0/1，恢复 1/1。点击两侧 Trace 说明严格校验和受控反馈。 |
| 1:20–1:50 | `mcp_disconnect` | 进度到第 4 帧：红色失败链路，没有后续读取或提交，没有已提交答案。此例是固定不可达端点故障注入。 |
| 1:50–2:15 | `time_limit` | 40ms 总时限遇到人为 250ms Fake 等待；明确时间终止、0 次工具、用量/费用未知。延时不是性能样本。 |
| 2:15–2:45 | `resumed` | 技术 Trace 筛选“从存档恢复”，看相同 Episode ID；查询只有一次，之后继续提交。生成器确实在保存工具安全点后退出子进程。 |
| 2:45–3:00 | 限制说明 | 动画按已保存事件回放，未抓包握手或 tools/list；实际 tools/list 用于生成时服务就绪检查。Fake 不证明真实模型能力、长期配额或外部写工具恰好一次。 |

`success` 是普通订单成功案例；`argument_baseline` / `argument_recovery` 可直接打开两侧；`documents_local` 与 `mcp_success` 已核验终态、Token 与工具数相同。总计一个 Experiment、八个 Episode。
