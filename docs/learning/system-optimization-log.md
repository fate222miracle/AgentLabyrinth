## 2026-11-13 双局 Judge 复用原版狐狸动画

等待区改为原版狐狸上移显形、五官显现和卷尾路径展开。现有生成器从同一原稿输出循环版，每次原动作后停留 670 ms。减少动效时使用静态标志。Edge 4 项、Web 类型检查和构建通过，另在 19922 预览以实际图片采样核对第二轮仍播放和减少动效时的静止画面。浏览器验证使用替身评审，未调用真实模型。

## 2026-11-13 四模型批次与 Judge 分析改进

实验中心可显式启动回廊档案室的四模型串行批次。固定同一任务、Seed 1、24 步、330 秒、最近两轮上下文、每局累计输入 160,000 阈值及每次输出 2,048 上限。批次清单在调用前原子保存，Episode 写入 SQLite。页面可查看状态及限定本批记录。后台串行、失败保留、进程中断后只读回看，重新运行由用户新建批次触发。当前执行互斥范围为一个 API 服务进程。

真实初版评审 f9aaca82-7d9e-432c-b5d3-c4533c764d13 复述了动作和指标。原 Trace 表明两局第 11 步分路，两条支路均继续产生新的公开观察。Judge v2 增加每次动作前可见邻格、行动后新发现格数与是否折返，要求解释为何某一步有影响、当时能看到什么和结论边界。v1 使用原输入指纹回查，预览重启前后该真实评审和 10 条摘要的响应文本一致。

76 项 Python 定向、54 项 Web 单元、11 项 Edge 定向、Ruff、4 文件 Mypy、Web 类型检查与构建通过。Edge 记录 196297fc-6882-4739-8b1a-1186892e0950。替身覆盖四模型都进入运行、单候选不可用、失败及中断状态、限制同批对比和 v1/v2 回查。预览中四模型按钮可用，检查全程只 GET。真实四模型批次与 v2 Judge 输出质量由用户实测，本轮没有真实推理、评审或 GitHub 提交。

同一模型 `coding-glm-5.3-flash-free`、同一关卡 `key-door-002-v1` 和 Seed 1，均完成 20 次模型请求。两局路线有差异，属于两次实跑记录。

累计输入少了 113,645 Token（69.6%）。第二局取钥匙、开门，停在 (5,1)。当时从该位置到出口的最短后续是右、右、下、下，共 4 步。独立的同轨迹离线对比只重建网关消息体，累计减少 73.3%。两项数据的口径分别为真实报告 Token 与离线序列化字节。

下一次新建真实第二关使用 24 轮、330 秒、累计 160,000 Token、每次输出 2,048。继续保留最近两次完整工具轮次，新增移动刷新、拾取同格和已知可走路线的指令。第一关、Fake、旧历史及原显式预算请求继续读取各自配置。预算理由、模型输入和兼容约定见 [ADR-049](../adr/ADR-049-gridworld-loop-gallery.md#2026-11-12-真实复测及新运行边界)。

### 本轮回归

使用本地模型替身重放最新样本的前 20 个动作并追加出口方向的 4 步。旧实现以 MAX_STEPS 停止，新实现按第 24 步通关，保持一次规则内拾取拒绝及两轮上下文。112 项 Python、Ruff、Mypy 和 Web 类型检查通过；Edge 的 7 项 GridWorld 回归及最终界面更新后的 3 项配置专项通过，生产构建通过。19922 预览已更新，最新真实失败记录在重启前后回读等值。新配置的真实模型表现待复跑。

### 首个模型请求超时

真实样本 `8c425323-a39b-4f48-9041-88b68bdcb197` 在第二关 24 轮、330 秒配置下运行 31.156 秒。Trace 记录首个模型请求，随后以 `provider_error: REQUEST_TIMEOUT` 结束，后端日志为 `operation=completion category=REQUEST_TIMEOUT`。无模型响应或环境动作。针对新建真实第二关默认配置，将单次 AIHubMix HTTP 连接/读取阈值从 30 秒提高到 60 秒。整局时限、步数和 Token 预算保持原值，同一次运行不自动重发请求。阈值由离线回归验证，上游实际响应时间待新样本验证。

旧实现的回归断言捕获了缺失的 60 秒参数，修正后 58 项离线测试及 Ruff、Mypy 通过。19922 已更新，原失败 Episode 在后端重启前后回读等值。
