# 同窗口工具记忆对照：源码与验收交接

日期：2026-10-15；SSOT：requirements.md V0.6；依据 [ADR-031](../adr/ADR-031-same-window-memory-ablation.md)。本轮 Codex 复核 Trae 已实现的正式入口，修复校验边界并接管后续主要技术开发；不代表整版 V0.3 签收，不提交 GitHub。

## 如何使用

1. 打开对照实验，选择“工具记忆：相同近期窗口 vs 相同窗口+记忆”。
2. 本地机制验证：Fake、clean、只选 `order-status-007`，N=1、M=8192；两组共同使用一种 Runtime 和恢复策略，再显式运行。
3. 左侧保留最近一轮完整工具交互；右侧同一窗口，加窗口外成功工具返回的有来源记忆。查看保存的两侧策略、通过结果、工具调用、报告 Token 和耗时，并穿透右侧 Trace 的模型请求节点查看记忆来源。
4. N=5/M=32768 时该 Fake 任务两侧都可通过；N=1/M=256 时两侧都失败。记忆不是必然有效，不能把第一个受控结果套用到其他任务。

刷新、浏览器前进/后退、查看 Trace 和下载 CSV 均只读；改下一次草稿不改变已保存结果。旧上下文轴仍为 full vs recent，单次默认 full。

## 源码阅读顺序

1. `apps/api/schemas.py::CreateExperimentRequest.global_token_revision`：请求 1.6 仅接收新轴，右侧必须是合法的记忆策略；旧默认 1.5 不变。
2. `apps/api/service.py::EpisodeService.prepare_experiment`：从右侧策略确定性派生左侧同 N 无记忆；模型、任务、Prompt、工具、预算与 Runtime 都固定。
3. `packages/application/experiment.py::_validate_memory_agents` → `create_experiment_plan` → `ExperimentCheckpoint.verify`：创建、写盘、回读、恢复都检查固定变量；计划 1.3 只属于新轴。
4. `run_experiment`：保存冻结矩阵，逐臂执行与复用完整 Episode。暂停/恢复、失败显式重跑、全局 Token 边界沿用既有路径。
5. `packages/runtime/context.py::project_context`：仅投影 Provider 输入；完整历史/Trace/安全点保持。记忆来源和字节预算沿用 ADR-030。
6. `ExperimentArtifact.token_budget_revision` → `EpisodeService.get_experiment`：结果 1.5 仅属于新轴，验证相同窗口、左无右有、Runtime 来源和无恢复挽救指标，随后核对保存配置哈希。
7. `scripts/run_regression.py::preflight` 与 `packages/application/regression.py::fixed_config`：支出前验证冻结条件；N、M 和轴进入原有比较指纹，不把不同配置混作趋势。
8. `apps/web/src/apiContracts.ts` → `App.tsx` → `ExperimentCharts.tsx` / `ExperimentDashboard.tsx`：校验保存结果后展示；CSV 沿用既有列，左记忆上限空、右为 M。

## 本轮发现并修复的共性问题

- **创建通过不等于恢复仍安全。** Trae 的创建入口检查模型/Prompt/工具/预算，但 `verify()` 中调用的记忆校验原本只检查窗口和 Runtime。现把除身份名称和上下文外的完整 Agent 固定字段检查放入共同校验器；即使修改后重算 `plan_hash`，混变量仍拒绝。
- **版本限制必须双向。** 原代码拒绝旧版本使用新轴，却接受新计划 1.3 / 新结果 1.5 挂到旧轴。现后端和 Web 均补反向拒绝；旧轴原有版本规则不改。
- **两侧同样缺失不能算一致。** 结果曾遗漏 `recovery_policy` 检查，Web 也未核对 Runtime 版本。现新轴必须保存且匹配 backend / strategy / runtime_version / recovery_policy；损坏的非对象臂配置产生校验失败，不因属性异常拖垮历史看板。

两项新增失败测试先在原实现复现 `DID NOT RAISE`，修复后通过。给后续协作者的防错规则：不要只测 HTTP 正常创建；同一不变量必须覆盖持久化读取、重算哈希后的非法计划、恢复和 Web 消费端。
