4. 原 `handleRunExperiment`/Job/Poll/冻结计划实现比较，完成后从保存的指标和两侧配置显示“上下文实验解读”。不把窗口差异当参数纠错挽救，不预设某侧胜利；Fake与真实小样本标识保持。原JSON/CSV、成对Trace穿透、历史回读与预算边界复用。
