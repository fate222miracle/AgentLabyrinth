7. `tests/contract/test_execution_time.py` → `tests/unit/test_api.py` → `tests/unit/test_regression.py`：读完失败断言后重跑实验，再看 Web。

## 调用链与状态变化

Web 秒数 × 1000 → 创建请求 → Service 配置 Budget 1.1 → Runner 创建 Trace → 独立 Runtime 调度 EpisodeSession → Observation → 模型前预算检查 → 剩余时间约束的 Provider 请求 → 记录响应用量 → 参数/权限校验 → 工具前检查 → 工具线程 → 返回结果与环境快照 → 检查总时限 → 保存安全点 → 下一模型或终止 → 独立 Evaluator → 唯一 `EPISODE_FINISHED` → 原子保存 JSON。

`started` 来自单调时钟；恢复使用 `当前单调时间 - 已保存 elapsed_ms`，因此暂停/进程停机时间不累加，而已保存活动时间不会归零。安全点没有新增字段，继续使用现有 `SessionState.elapsed_ms`。未落盘阶段的真实耗时不能从安全点精确追回，这与既有请求可能重发的语义一致。

工具已经开始后，线程继续完成；成功/失败事件和可获取的快照保留。晚到的成功提交仍以总时限超限结束，Runner 不把环境 `done=true` 当作预算通过。没有第二次自动工具执行，也没有回滚承诺。

## 失败路径

| 触发 | 保存内容及后续行为 |
| --- | --- |
| 模型等待超过剩余总时间 | 请求事件保留，未收到响应不补造响应；终止详情带 `upstream_usage_unknown`，费用总额未知，Token 数只代表已收到的报告，不自动重试。 |
| 模型自己的局部超时 | 剩余总时间未耗尽时保留 Provider 错误类别，不误报为总时限。 |
| 已收到响应后超限 | 先计入响应的完整 usage 并记录响应；不开启校验或工具。 |
| 工具执行后超限 | 保留工具结果与快照，终止后续行动；工具线程可能超过截止时间才返回。 |
| 恢复安全点已耗尽时限 | 不请求模型、不执行新工具，延续原 Trace 并产生唯一终态。 |
| 安全点写入失败 | 仍按既有 CheckpointFailure 中止；不能宣称可靠落盘。 |
| 历史 GET/404 | 读取文案与执行文案分开；不发起模型请求，404 明确显示。 |

异步超时取消的是本地等待，不能保证已发出的上游 HTTP 请求或线程被杀死；上游最终用量可能未返回。总时限不替代工具的局部网络超时，也不是外部写操作幂等机制。

## 当前演示操作

- Web 新运行默认 300 秒；单次运行的时限在高级选项，对照页两侧共用“每次运行时限”。保存结果显示原配置的时限，旧历史显示“历史配置未设置”。
- 实验历史与趋势默认折叠，配置组附 Seed/重复次数和短比较键，展开后仍使用原来的兼容组规则。
- 流程动画“专注查看”进入浏览器全屏；桌面并排展示输入/最终输出，中间放大图形。播放、逐帧、速度和可选记录继续有效；退出按钮/Esc 返回，焦点回到入口。窄屏保持可滚动，不把文字截掉。
- 这始终是已保存或已收到 Trace 的视觉呈现；不重放工具，不声称有握手/tools/list 抓包。真实模型与 Token 配置本轮保持原行为，Token 标签纠正为每次运行。

## 数据库的后续改造候选（未实施、未形成 Accepted ADR）

先明确需求与独立 ADR，再把应用层的 Artifact/Checkpoint/Experiment/Job 文件读写抽成持久化 Port，保留 JSON Adapter 与导出格式，Domain/Runtime 不直接依赖数据库。对课程规模可评估 SQLite；实现时需要版本化迁移、Episode/Trace 顺序及唯一性、原子安全点与 Job 控制事务、旧 JSON 的显式导入和哈希核对。先做同一契约的 JSON/数据库恢复对照，再考虑共享队列、多 worker 与其他数据库。

数据库不能自动解决上游请求重复或外部写工具恰好一次，也不能把本地单进程 Job 保证直接扩大成多 worker 保证。不要先建空模块或悄悄迁移现有产物。
