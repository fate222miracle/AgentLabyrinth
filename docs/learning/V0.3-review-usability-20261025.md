## 用户现在能做什么

- **结果复核**：说明这是运行结束后的可选检查，用于记录对答案、依据和工具使用的认可或质疑；不需要逐步审批工具，也不覆盖规则评分。
- **记录我的检查**：填写整体结论、三个明确问题和检查说明，按需关联执行记录。无最终提交时仍限制整体结论/答案/依据，允许记录过程问题。
- **已保存检查**：人工与真实模型记录显示结论、理由及三个维度；未知称“暂无法判断”，不补造判断。失败说明没有产生质量结论，并保留失败码。
- **技术详情**：原量表/提示版本、保存模型、独立评审 Token/模拟标识、未知费用和价格版本按需展开，默认不堆满界面。
- **模拟测试（开发用）**：按钮和所有 Fake Judge 历史单独收进默认关闭的区域。明确不评分、不调用真实模型，正常记录显示“模拟记录已生成”，失败显示“模拟测试未完成”，不再渲染三项虚假质量结论。原始说明仍能展开查看。
- **导出全部记录 CSV**：包含人工、真实模型和模拟记录，保留原 method/provider/status 与所有旧列/转义/未知金额规则，便于完整追溯。页面分组不删改历史产物。

4. `apps/web/src/index.css`：复用原生 details/summary，无新依赖；键盘焦点、窄屏断行、原理由换行和减少动效保持。详情展开与关闭不创建评审。

状态仍为读取中/失败/显式保存/回读。API 失败不能用空列表冒充成功；真实评审失败没有 verdict；模拟失败不能解释成被测 Agent 失败。新开页面与刷新都默认收起模拟和技术详情，不自动生成记录。没有新增真实 Judge 产品入口。
