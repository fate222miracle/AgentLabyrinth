# V0.2 ToolLab Checkpoint/Resume 阅读说明

## 解决的问题与范围

单次 ToolLab Episode 的运行进程意外退出后，原先只有已经写出的最终 Artifact；模型消息、预算、工具结果和环境状态无法继续。当前实现只在完整安全点保存这些信息，并允许另一进程继续同一 Episode。它不处理 BFCL、外部写工具或批量 Experiment，也不保证上游模型请求恰好调用一次。

## 阅读顺序、入口与调用链

`docs/adr/ADR-011-tool-lab-checkpoint-resume.md` → `packages/application/checkpoint.py` → `packages/application/runner.py` → `packages/runtime/session.py` → `packages/runtime/handwritten/budget.py` → 两个 Runtime → `packages/application/trace.py` → `tests/integration/test_checkpoint_resume.py`。

新运行入口是 `run_checkpointed_episode`；恢复入口是 `resume_checkpointed_episode`。前者建立 Recorder，Runner 写 `EPISODE_STARTED`，Runtime 的 Session 执行 observe/model/validate/execute；安全点回调把 Session、Trace 和配置合成一个 JSON，再以同目录临时文件 `os.replace` 原子替换。Runner 评测并写唯一终止事件，应用层写最终 Artifact 后清理 Checkpoint。恢复时先检查已有最终 Artifact，再读取并校验 Checkpoint，重建 Recorder，Runner 追加 `EPISODE_RESUMED`，Session reset/restore 环境和预算，按 `next_node` 继续。API 的 `EpisodeService.execute_episode` 对 ToolLab 使用新入口，BFCL 保留原流程；服务重启后列表仅展示旧进程留下的存档，Web 单次运行区可发起恢复。

## 关键对象与状态变化

- `SessionState`：版本化的 Agent 可见消息、已见 Call ID、纠错标记、预算、环境快照、下一节点和停止信息。仅在模型前或终态保存。
- `BudgetState`：当前次数、Token、费用及模拟/未知费用状态；恢复后不从零开始。
- `EpisodeCheckpoint`：绑定 Episode ID、Agent/Task/RunConfig 哈希、Trace 和 Session。配置不符、事件链断裂、终态 Trace 或不匹配的 ToolLab 版本直接拒绝。
- `JsonTraceRecorder`：把原事件链恢复到同一 Episode；后续事件以原尾事件为父节点。

正常路径中首次查询工具执行成功，ToolLab 环境快照和 Call ID 同时进入安全点；新进程从该快照继续调用模型提交答案，查询工具不会重跑。模型请求中断若尚未进入下一安全点，将从旧安全点再次请求；因此真实上游的请求次数和费用可能高于 Checkpoint 内账面值。

## 失败和停止条件

Checkpoint 写盘失败抛出 `CheckpointFailure`，不能伪装为成功 Artifact。损坏、外来 Episode 或配置哈希不匹配拒绝恢复；不会静默开新 Episode。Runtime 原有预算、未知工具、禁止工具、重复 Call ID 和一次参数纠错边界保持不变。已存在最终 Artifact 时只读取，不重调模型。ToolLab 工具的状态仅在进程内，安全点前的进程退出不会留下外部写入；真实外部写入工具需要额外的持久化幂等键/事务协议。

## 最小实验与结果

在项目根目录运行：

```powershell
.venv\Scripts\python.exe -m pytest tests/integration/test_checkpoint_resume.py -q
```

实验将子进程停在首个成功工具后的安全点，再以另一进程通过 HTTP 恢复。Reference 和 LangGraph 两侧均通过，最终各 2 次模型调用、2 次工具调用、80 prompt tokens，原工具只执行一次，Trace 有一个恢复事件和一个终止事件。另测 Fake 参数纠错中断后可继续成功（3 模型调用、2 工具调用）、Task 篡改拒绝与正常完成后清理。浏览器也用 Fake 存档完成后端重启、列表、点击恢复、Trace 与 URL 刷新回读，Episode `2315b4b2-4001-4e74-8807-7073ba77cafb`。两侧不是模型能力对照，均使用 Fake；不能由此推出真实模型得分。
