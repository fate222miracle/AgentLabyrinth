# V0.2 原厂参考成本与实验预算交接

阅读顺序：需求 V0.6 FR-08 → ADR-017 → `packages/application/official_reference_prices.json` → `reference_pricing.py` → `runner.py` → `experiment.py` → API schema/service/main → Web `App.tsx` → `tests/unit/test_reference_pricing.py`、`tests/integration/test_reference_budget.py`。

## 调用链与状态

模型调用结束后，Runner 只在 AIHubMix 非模拟调用、每次模型请求均有响应且 usage 完整时，用版本化原厂价格表计算 `EpisodeArtifact.reference_cost`。现有 `estimated_cost` 保持网关费用口径；未获可核验账单时仍为未知。Experiment 将每侧参考成本及汇总写入产物；旧产物缺字段仍可读，不能追溯套用新价格。

API 接收可选 `max_reference_cost_usd`，只允许当前四个精确免费模型 ID 使用。运行计划记录预算与价格版本；每个已完成 Episode 的参考成本加入账本，达到或超过阈值后不启动下一 Episode。超额发生在已启动 Episode 结束时，保留它的 Artifact 与计划并报 `REFERENCE_COST_BUDGET_EXCEEDED`。恢复从已有 Artifact 重建累计值，价格版本变动或用量未知时拒绝继续。该预算限制的是原厂标价参考值，不能约束 AIHubMix 实际扣费，也不能硬停止正在运行的一题。

Web 分开显示“网关费用”和“原厂参考成本”，导出的 Experiment CSV 增加参考成本列。原厂页面虽列缓存价，但当前网关 usage 没有可靠的缓存命中拆分，因此全部输入按未命中缓存价估算，可能高估。

## 失败路径与验证

- 未知型号、Fake、没有有效 usage 或未完整返回：参考成本保持未知；预算运行拒绝将未知按零累计。
- 新旧价格版本不一致：计划恢复拒绝混算。
- 单题可能超过剩余预算：在途调用不会被中断，结算后停止下一题。
- 单元测试核对四个精确 ID 与未知 ID；集成测试以确定性替身模拟网关 usage，检查网关费用未知、参考成本已知，以及超额后已有 Episode/Checkpoint 保留。
- 2026-09-30 真实探索：`coding-minimax-m2.7-free` 运行改编 BFCL `bfcl-simple_python_1`，Episode `b4602664-9f62-4133-8b58-cf68c3e8c60f` 成功，1 次模型调用，234 输入/63 输出 Token；网关费用未知，原厂参考成本为 `$0.0001458`，价格版本 `official-reference-2026-09-30`。仅证明本次连接和计算路径，不代表官方 BFCL 分数或持续可用。

原厂标价与来源固定在 ADR-017；调价须发布新版本，不能直接改写旧产物。真实美元账单上限仍需网关可核验的价格或扣费数据。
