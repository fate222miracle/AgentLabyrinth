# ADR-030：近期上下文中的受限单任务工具记忆

状态：Accepted，2026-10-14。负责人明确选择接续V0.3单Agent上下文与记忆开发；依据需求V0.6 §19、ADR-023/026。这里只扩展已使用的ContextPolicy，不启动多Agent、数据库、摘要模型或跨任务记忆。

## 问题与决策

近期窗口会忘掉已经成功返回的搜索/阅读结果。增加可选、确定性的单Episode工具记忆：从被窗口排除的完整工具轮次中，选择最近的成功结果，按原顺序将完整返回及call_id/工具名放入模型可见初始user观察的独立数据字段。不是摘要、知识真值或新的工具执行；内容是未经信任的工具数据，不具有指令权限。

- ContextPolicy旧schema1.0/算法tool-round-window-v1不变；新schema1.1/算法tool-round-window-memory-v1仅允许recent_tool_rounds，要求memory_max_bytes为256–32768整数。旧配置无此字段，序列化省略None，旧哈希保持。
- 新子契约随Agent/API/冻结计划/Artifact现有配置保存；外层版本不改变，因为上下文已显式版本化且旧版本仍可读。新读取者必须验证子版本组合，不把新算法降级成旧窗口。
- 仅从成功消息的result结构提取实际工具返回；纠错error反馈、未返回/失败调用、任务私有目标、环境快照和最终状态均不可作为记忆来源。当前Session只为成功执行追加result反馈，参数错误使用error反馈；其他环境无此成功结构时跳过，绝不推断。
- 不切片单个结果、不提炼答案、不按任务ID选内容。超过字节预算的整条记忆跳过；从最新开始选择、输出按历史顺序，不改写冲突信息。预算包括完整记忆数据包的紧凑UTF-8 JSON，不是Token预算；最终输入和真实用量仍走原Provider预算。
- 只在投影深拷贝中增加_agentlabyrinth_memory数据字段；初始观察出现该保留字段则拒绝，不覆盖已有数据。Session/Trace/Checkpoint继续完整保存，恢复从原历史重建相同记忆，无额外模型/工具调用。
- MODEL_REQUESTED现有context诊断增加记忆条数、跳过数、实际字节和源call_id；无记忆策略保持原诊断。正文不重复存入诊断；Web只显示当前事件已有的记忆来源，不从未来事件补数据。
- 单次Web提供full/近期窗口/近期窗口加记忆；现有上下文对照可配置右侧记忆，与full比较整体上下文策略，不将差异单独归因于记忆。离线三组full/window1/window1+memory提供相同窗口的记忆消融，Fake只验证机制。

## 验收与边界

验证旧序列化、非法组合、全历史协议错误、复制隔离、错误结果排除、超大返回整条跳过、UTF-8精确预算、相同call来源、两Runtime遗忘/记忆对照、恢复重建与篡改拒绝、API及Web保存回读和只GET历史；记录源码/调用链/失败/实际结果。

该策略可能增加输入量、丢失太大的返回或保留无关内容，不保证成功率或Token收益。不是持久知识库、语义检索、LLM摘要、安全过滤或论文新算法。真实模型若未运行只记录未验证，不拿Fake固定Token作真实节省结论。不提交GitHub。
