# ADR-018：同配置实验历史看板

## 状态

Accepted（2026-09-30）。依据需求 V0.6 FR-09、§11、V0.2 路线；用户授权先补可靠性实测与回归基线，再收口看板与验收文档。

## 决策

1. 在现有只读 Experiment 列表 API 中增加可选的模型、任务矩阵、场景、故障、原厂参考成本与比较键，响应版本扩为 1.1，旧字段保留。比较键复用固定回归的 `fixed_config` 哈希，固定模型参数、任务版本、Prompt/工具、预算、环境/评分协议、Seed/Repeat、故障与对照策略；实现版本允许变化。
2. Web 可按比较键筛选兼容历史实验，仅在同组至少两次完整运行时显示最近两次的成功率百分点、Token 与平均耗时差值。每次运行的两侧仍分别展示；不计算跨组总分或排名，不将一次变化称为统计显著性。
3. 缺少完整协议来源的旧产物照常单独展示，比较键为未知，不纳入趋势。配置哈希不匹配、Pair 数量不一致或文件损坏的结果跳过并提示数量。网关费用未知与原厂参考成本分别展示；旧产物不重算。
4. 继续使用已保存 Artifact、原生筛选控件和进度条，不增加图表依赖、后台任务或模型调用。列表展示最近 100 条并明确这个范围，详情跳转仍为 GET。

## 验收

只读测试禁止模型调用；同配置结果比较键一致，模型/Seed/场景变化不混入；旧产物有中性降级；损坏与篡改文件不遮蔽有效记录。Web 验证加载、失败、空列表、筛选、窄屏与键盘焦点。

## 边界

该历史差值服务于本地实验排查，不是模型排行榜、显著性分析或通用 Benchmark 官方分数。当前索引仍读取本机 JSON，数据量大到影响读取时再引入分页或数据库索引。
