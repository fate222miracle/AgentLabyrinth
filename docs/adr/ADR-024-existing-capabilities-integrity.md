# ADR-024：已实现能力的可信度与演示闭环优化

- 状态：Accepted
- 日期：2026-10-04
- 授权：负责人要求优化目前已实现功能，暂无时间人工验收。
- 依据：需求V0.6 §4、§11、§12、§13、§20、§27；ADR-018/019/021/023。

## 发现与决策

1. `regression.fixed_config` 尚未包含新context_policy；相同其他配置但窗口不同会取得相同比较键。显式上下文策略加入每侧固定变量并严格按ContextPolicy校验，缺省/null继续省略以保持既有基线指纹；不重算旧Artifact、不增加新对照轴或评分。未知/非法策略不参与趋势或回归。
2. 完整Episode结果目前可能使安全点从恢复列表消失，直接恢复还可能返回文件名与内部ID不同的结果。复用前核对请求ID与事件归属；安全点存在时还核对双方配置哈希及Agent/Task/RunConfig是否一致。语法损坏JSON仍可由有效安全点重建；结构完整但错身份/来源明确拒绝，不静默覆盖。没有安全点的历史完整结果维持只读兼容，不重算旧配置哈希或做迁移。
3. Context CLI仅保存Episode，未保存既有Fake输入来源，页面重跑因此被拒绝。生成时采用既有episode-inputs schema1.0，保存success场景与Episode ID；正式Service用原Agent/Task/RunConfig、新ID运行，窗口失败仍失败，不能称为优化成功。旧缺来源文件仍不猜场景。
4. Context预览只信报告expected_outcomes_match标记。新增报告与24个实际Artifact交叉核验：身份、哈希、固定矩阵/单变量、模拟用量、实际指标、请求诊断和预期结果；只读、不重评历史、不改评分，报告缺失/错误拒绝预览。使用原子写入诊断报告。此为完整性检查，非加密认证或真实模型能力证明。
5. 请求投影与深拷贝也消耗执行时间；构造完消息再检查剩余时限，已经到期时不得发出Provider调用或增加模型计数。沿用TIME_BUDGET_EXCEEDED，不新增Trace类型或预算Schema。
6. UI规范§10要求减少动效。既有CSS会隐藏SVG数据包，但仍创建animateMotion；读取并监听媒体偏好，减少动效时不生成该动画，保留静态状态与用户主动播放/切帧。补390/768/1280/1440px画布适配、顶部导航、键盘与动态媒体偏好浏览器验证，不将媒体模拟称为Windows系统设置验收。

## 范围、验证与回滚

仅优化已有能力，不增加数据库、框架、Memory/Planning/Reflection或新建上下文实验页面。API/Domain/报告外层Schema不变。界面补真实产物读取→原策略失败重跑的自动闭环，确保原文件不改写。串行修改，保护已有未提交改动；无Git发布或真实模型调用。

先以失败用例复现，再修正；完整质量门禁、旧四套回归及24个上下文案例必须通过。自动通过/人工未验分开记录，负责人实机、第二电脑、课程现场与版本签收仍待完成。回滚仅撤销本轮保护逻辑，不覆盖历史产物；不能把不同上下文重新混为同配置趋势。
