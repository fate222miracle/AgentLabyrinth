# ADR-006：真实模型故障诊断与显式运行预算

## 状态

Accepted（2026-09-20；用户要求测试免费模型并修复失败原因）

## 证据

真实 GLM 返回过工具调用，但 filters 为字符串；第二轮累计 usage 为 1474，超过任务 1000 Token。另有 HTTP 429、404、no_available_channel，而 Runtime 全部抹平为 provider_error。

## 决策

- Provider 通过框架无关的 ModelProviderError 向 Runtime 提供固定白名单错误码。HTTP 响应正文、密钥及异常文本不进入 Trace；未知异常仍归为 provider_error。不对上游故障自动重试或自动换模型。
- 保留严格参数校验，禁止把字符串化对象自动修成对象。Provider 仅将工具 JSON Schema 中本地 `$defs` 引用展开为等价 schema，以减少网关兼容差异；不改变工具语义。
- Episode 与 Experiment 请求增加可选 token_budget（100–20000）。省略仍使用原任务预算；指定后任务快照、哈希和实验固定变量记录实际预算及原预算。两种策略使用相同覆盖。UI 对真实模型展示 8000 的可调默认值，Fake 默认仍保持原任务预算。
- Agent 的真实模型预算同步设为明确的总预算上界；单次生成 max_tokens 上限为 1024，实际累计用量仍受 Runtime 硬限制。预算为响应后核算，不能保证供应商费用绝不超出预估。
- 模型目录保留失败模型供人工重测，展示带日期的实测结论，不把单次失败当永久禁用。移除“用量报告正常”的无日期保证。页面说明免费模型配额可能限制多轮成对实验。
- 不改变 TaskSpec/Trace 持久化 schema；预算覆盖写入现有任务 evaluator_config 的运行元数据。新增请求字段可选，旧调用和历史产物继续可读。

## 验证

固定错误码脱敏测试、Runtime 错误传播测试、引用展开等价性测试、API 两种策略相同预算及保存回读测试；联网探测单独存档，不作为离线测试依赖。
