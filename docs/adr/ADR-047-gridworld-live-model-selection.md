# ADR-047 GridWorld 真实模型选择

**状态** Accepted，2026-11-10 负责人确认将本任务交由 Copilot 开发。承接 ADR-045 的地图规则与 ADR-046 的信息隔离和预算。

## 现状

浏览器端口 19821 连接隔离的 DemoService，其模型目录只有 Fake。当前 GridWorld 的正常 API 也要求 Fake，并在前端锁定该选项。此前 MiniMax M2.7 Free 是一次独立验证，使用同一地图、Runtime 和固定预算。模型取得钥匙，第 7 次响应后因累计输入超过预算终止。测试时观察中缺失可见门 ID，现已补齐并通过离线回归。

门 ID 修复后，以临时 100,000 累计 Token 运行一场隔离复测。相同型号、Seed 1 和手写 Runtime 下，8 次请求、8 个动作通关，模型按观察返回的 `door-amber` 开门。输入 27,144、输出 212，合计 27,356 Token，耗时 93.187 秒，费用未知。两场的预算与观察契约都有差异，这次只验证当前配置可以走完任务。实验通过独立进程适配固定 TaskSpec 的预算校验，网页与产品 API 接入仍由本 ADR 决定。

## 决策

- 在正常 API 服务的独立 GridWorld 页面提供 **Fake** 与 **MiniMax M2.7 Free**。首次只准入现有配置中的 `coding-minimax-m2.7-free`，可用性沿现有模型目录和服务端准入校验。由任务元数据的可选 `allowed_model_ids` 列出可选 ID，前端取它与当前模型目录的交集。默认选 Fake，离线预览继续通过原有 DemoService 提供 Fake 目录。
- 扩展现有单次创建请求的 GridWorld 分支。选择真实模型时，显式发送 `provider=aihubmix`、所选模型及 `scenario=null`。服务端在任何 Provider 请求前校验允许型号、固定任务和完整预算。GridWorld 仍使用手写 Runtime、single 工具模式及 Agent 可见观察。仅点击「开始运行 Episode」触发推理，实时区标出真实模型与实验性来源。
- **真实模式使用临时验证额度。** 服务端为 GridWorld 真实运行冻结 **100,000 累计 Token（输入与输出合计）**，同步设置累计输入上限为 100,000。现有 **16 轮、单次输出 800、累计输出 12,800、300 秒**继续约束单场。上一场单轮输入从 1,172 增至 4,544，原累计 16,000 在第 7 次响应即被超过。临时额度旨在先观察完整任务表现，再根据实测确定长期预算。
- 真实请求省略 `token_budget` 或传 `null`，由服务端选择临时验证额度并保存实际任务/Agent 配置和来源哈希。其他数值在调用 Provider 前拒绝。Fake 保持 16,000，ToolLab 与 BFCL 仍使用各自原有请求上限。GridWorld 任务校验和评测只接受这两个已知配置与各自运行来源，地图与公开任务字段继续严格校验。
- 已知费用沿原规则在响应后核账，未知费用单独展示。真实调用停止时保留已报告用量、实际 Trace 与失败结果，页面明确展示临时额度。
- 真实结果复用正常单次执行、保存、实时事件与只读回放。首次交付限定新建真实 Episode。显式恢复或重跑真实 GridWorld 等入口须先校验来源与支持范围，历史刷新和导航始终为 GET。

## 验收

1. 正常服务能在 GridWorld 独立页面选择已准入型号，目录不可用时呈现实际可选项及原因。离线预览仍只有 Fake，伪造真实请求在 Provider 调用前被拒绝。
2. 用本地替身验证模型 ID、single 模式、预算、一次显式启动、真实来源标签、费用未知及网络错误状态。确认初始/中途/终态的模型输入、实时事件、保存产物和回放只携带 Agent 可见信息。
3. 验证正常完成、预算结束、历史回读、Fake 场景与旧任务的兼容。验证真实运行记录实际的 100,000 配置，非法预算在请求 Provider 前被拒绝。负责人可以从正常服务亲自运行一场真实验证，并核对是否使用观察返回的门 ID。

批准项为在正常 GridWorld 页面开放上述真实模型的单次运行，并采用 100,000 临时额度。取得完整运行数据后再评估长期额度。

## 2026-11-12 真实三维演示额度

负责人要求先接通真实模型并放宽 Token。新建真实运行冻结 `temporary-real-160k-v2`，累计输入与总量上限均为 160,000，单次输出上限为 2,048，累计输出上限为 32,768。维持 16 轮、300 秒、现有真实模型白名单、费用规则与只读历史。旧 100,000 配置仍可校验和回读，Fake 继续使用原预算。验证使用一场真实的钥匙与门任务，浏览器与三维舞台共用同一条实时 Trace。
