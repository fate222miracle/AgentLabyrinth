# ADR-042：损坏评审历史的有限读取

状态：Implemented；2026-10-28负责人要求完成已发现问题，含损坏评审隔离和不完整提示。范围仅为只读历史，不改变评分或保存数据。

旧GET默认返回1.0且遇损坏继续失败，保护旧客户端不会把不完整列表看成完整。新客户端显式带`include_integrity=true`，返回1.1及`unreadable_count`：对无法读取、无法验证身份或目标来源不匹配的文件计数，不回显内容/路径；归属未知的坏文件不能假定属于任何Episode。有效目标评审仍须来源校验，缺目标Episode仍失败。页面展示已有结果和全局不完整警告，不显示“尚无评审”或提供看似完整的CSV；实验汇总有任何不完整时不展示覆盖统计。GET不调用模型、不修改文件，历史文件及评分保持。扫描目录整体不可访问仍返回错误，不伪造零。此方案不解决分页或数据库。
